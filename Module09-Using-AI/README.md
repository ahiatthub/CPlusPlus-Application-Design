Module 9 Setup Assignment
I implemented a mock AI backstory generator for my characters. With the access to include an AI service in the program, it would take the name, class, and weapon of the character and generate a unique backstory to show when the character is displayed. For my mock implementation I used if statements to generate a specific sentence based on the choice of weapon and the choice of class, thus making it the same everytime the same weapon and class are chosen. This backstory is also saved to the file and can be loaded back in with the character. The AI generator would be integrated into my Character class the same way the mock generator is and used during the construction of each character object.
