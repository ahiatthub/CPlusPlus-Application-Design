I chose to research PyTorch and it's applications. PyTorch is an open-source machine learning and deeplearning framework. It incorporates a user friendly Python interface with a high functioning c++ backend. The main benefits of using c++ for the backend of PyTorch, as well as other applications, is that it has incredibly high performance. This is partially because the compiler converts it directly into machine code, where other languages may pass through several other things, lenthening the process between the source code and the actual execution in the CPU. C++ also allows for advanced memory storage control, which can be incredibly useful for something like open-source learning and deep learning, which take up high amounts of memory storage. With the precise control the C++ allows, it can allow the programmers to optimize storage. Finally, c++ is incredibly good for scalability, which is quite prevelent in AI programs.
